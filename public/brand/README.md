# JP branding

The selected ivory angular JP concept is preserved in `jp-concept.png`. `jp-mark.svg` is a simplified vector recreation for crisp masthead and colophon use. The charcoal tile preserves contrast in both themes. Browser and Apple icons use the same mark.

Concept created with the built-in image generation tool. Prompt direction: ivory interlocking JP monogram, diagonal cuts and negative space on charcoal.
